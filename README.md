Verilog Basics 🚀

A beginner-friendly collection of Verilog HDL projects developed while learning Digital System Design and FPGA development.

Projects

1. Half Adder

- Performs binary addition of two 1-bit inputs.
- Generates Sum and Carry outputs.

2. Full Adder

- Adds three 1-bit inputs.
- Generates Sum and Carry outputs.

3. 4-bit Ripple Carry Adder

- Performs 4-bit binary addition.
- Uses carry propagation between stages.

Testbenches

- Half Adder Testbench
- Full Adder Testbench
- Ripple Carry Adder Testbench

Tools

- Verilog HDL
- Xilinx Vivado
- FPGA Development

Learning Objectives

- Understand combinational logic circuits.
- Practice RTL coding.
- Learn Verilog simulation and verification.
